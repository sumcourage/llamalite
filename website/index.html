本地大模型，一键跑起来

Llamalite 是一个跨平台桌面应用。它帮你从 ModelScope 下载 GGUF 模型、可视化配置并启动 llama-server，实时查看日志 —— 全程不需要打开命令行。

Features

从下载模型到启动服务，都在一个窗口里

五个模块覆盖 llama-server 的完整生命周期：检测硬件、下载模型、配置参数、启动服务、排查问题。

仪表盘

服务状态总览、本地模型数量与磁盘占用一目了然，常用操作（启动 / 停止 / 重启 / 打开 Web UI）放在最顺手的位置。

服务管理

两种配置模式：快速配置只需选一个本地模型和使用场景，采样参数、上下文长度、GPU 卸载层数、线程数会按你的硬件自动调优；高级配置则开放 host、port、ctx-size、gpu-layers 等全部 llama-server 参数。启动后日志实时流式输出并自动滚动。

模型管理

浏览本地已下载的 GGUF 模型，从 ModelScope 搜索并下载，下载日志可折叠、可取消；也能单独下载某个仓库里的单个 GGUF 文件。

硬件检测与推荐

通过 sysinfo 读取 CPU、内存与显卡信息，再结合可用显存给出模型规模的量化推荐，避免选到跑不动的模型。

环境检查

自动校验 llama-server、Python 与 modelscope 依赖是否就绪，缺失时给出分平台的安装引导，省去逐个排查的时间。

How it works

三步，从零到可用的本地推理服务

下载模型

在模型库里搜索，或直接采用系统按你的显存推荐的结果，下载对应的 GGUF 量化文件。

配置服务

选择快速配置让参数自动适配硬件，或用高级配置精细调整 ctx-size、gpu-layers 等参数。

启动并使用

一键启动 llama-server，日志实时可见；服务就绪后直接打开内置 Web UI，或把任意兼容 OpenAI 接口的客户端指向它。

Tech stack

体积小、启动快，原生编译的桌面应用
